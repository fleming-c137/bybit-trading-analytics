Analyse your own account

Paste a read-only Bybit API key. Create one under Account, API Management, with only the read permissions for Unified Trading.

The key goes over HTTPS to this site's serverless function, is used for this one request and is never stored or logged. Your browser keeps only the results, and only until you close the tab. Keys with an IP allow list won't work here; run the project locally instead.
